# Metabolomics Utilities

This repository contains a collection of general scripts and code snippets that I use in the context of **metabolomics research and data analysis**.

**Disclaimer**:
This repository is a personal project and is not affiliated with or endorsed by my current employer. The code is provided as-is, primarily for my own workflows. While I may occasionally use parts of it in my professional work, the repository is maintained independently.

---

## Purpose

The scripts here are:

* Tools, helpers, and pipelines that I regularly use or experiment with.
* Focused on **metabolomics, mass spectrometry, and data processing**.
* Written for **personal and research use**, not as a polished software package.

Even though this codebase is not designed as a general-purpose library or package, you are welcome to browse, use, or adapt anything you find useful.

---

## Audience

* **Myself**: for reusing and adapting snippets across projects.
* **Other researchers**: if you stumble upon this repository and find a function or script useful, feel free to copy, adapt, or extend it.

---

## Usage

Since this is not released as a package:

* Scripts are intended to be used directly or adapted into your own workflows.
* Dependencies may vary between scripts (typically R with tidyverse, Python, SQL, or MATLAB).
* I recommend checking the header of each script for comments on requirements and usage.
